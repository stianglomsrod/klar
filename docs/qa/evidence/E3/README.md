# E3 – delt ansattdeltakelse i hjelpekø

Denne mappen inneholder syntetiske Chromium-bevis fra den autoritative lokale
E2E-fixturen. `shared-queue-participant-*` viser samme aktive kø sett av den
andre ansatte etter eksplisitt «Bli med», før personlig «Forlat køen».

Bildene er dokumentasjonsartefakter, ikke automatiske golden-mastere. Testen
kontrollerer i tillegg semantikk, axe A/AA, horisontal overflow, målflater og
databaseutfallet etter at den ansatte forlater køen.
