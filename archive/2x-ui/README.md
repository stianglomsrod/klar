# Arkivert Klar 2.x-kildekode

Dette er den tidligere 2.x-rutetreet og tilhørende klientkode. Arkivet er
bevart som design- og utviklingshistorikk, men ligger utenfor `src` og er derfor
ikke en del av Next.js-bygget, TypeScript-kontrollen eller pilotens runtime.

Koden forventer 2.x-skjemaet i [`../../supabase-2x`](../../supabase-2x) og skal
ikke kobles til 3.0-databasen. Eventuelle gjenbrukbare ideer skal implementeres
på nytt gjennom 3.0-autoriseringen og migrasjonslinjen, ikke flyttes tilbake
direkte.
